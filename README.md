**Information.**
  This Python function can be utilized to parse an SBML (Systems Biology Markup Language) file. Upon execution, it initiates a dialog prompting the user to select the desired SBML file for reading. The output includes information about the model and the file path. The output will be saved as a JSON file and also displayed in several pop-up windows

**Dependencies or Required Libraries.**
  This Python script requires the following libraries to be installed. Please ensure that these libraries are present in your Python environment before executing the script. You can install these dependencies using pip.

- json
- libsbml
- math
- numpy
- os
- PyQt5
- re
- sys
- sympy
- tkinter
